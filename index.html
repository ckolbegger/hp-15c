STAGE 02 / SCIENTIFIC FUNCTIONS

Start with 2 ENTER 3 + — the result is 5.

Think in reverse Polish.

Enter the first number, press ENTER, enter the second, then choose an operation. There is no equals key.

Try 12 ENTER 3 ÷ for 4. ENTER duplicates X; the four-register stack holds intermediate values.

Your keyboard is a keypad.

0–9 . Numbers · Enter ENTER
+ − * / Arithmetic · E EEX · C CHS
Backspace Delete · Esc Clear X
F / G Shift · O Power

On the calculator, g → ← clears X and g → ENTER recalls LAST X. R↓ rolls the stack; x⇄y swaps X and Y.
